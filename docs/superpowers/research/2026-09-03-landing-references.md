## 4. 공통 패턴

- 컨테이너 폭 1200~1280px. 히어로 제목 50~90px. 본문 16~20px.
- 내비: 회사 소개 / 제품(사업) / 소식(블로그) / 채용 / 문의. 슈퍼베이스는 제품, 소개, 소식, 문의 4개.
- 홈 골격: 미션 히어로 → 제품 카드 그리드(아이콘, 이름, 한 줄, 바로가기) → 일하는 방식/가치 → 소식 → 문의/채용 CTA → 사업자 푸터.
- 제품 카드에는 아이콘과 스크린샷이 있어야 회사 느낌. 텍스트만이면 포트폴리오로 보임. 오늘의모임 캡처와 앱 아이콘 확보 필요.
- 버튼: 필(999px) 또는 6px 라운드, 검정 또는 브랜드 컬러 단색, 그림자 거의 없음.
- 푸터: 상호, 대표자, 사업자등록번호, 주소, 이메일. 국내 관례.

## 5. 다음 세션에서 결정할 것

1. 톤: 당근 팀(따뜻함) vs Panic(제품 중심 절제) vs 37signals(목소리 중심)
2. 폭: 1200 vs 1280, 히어로 풀블리드 여부
3. 제품 카드에 넣을 시각 자산(아이콘, 스크린샷) 준비 가능 여부
4. 소식(블로그) 섹션을 이번에 만들지
5. 푸터에 사업자등록번호·주소를 공개할지
